# 大肥鱼踩坑对照卡

- printf 里的 %Y-%m-%d 要双写百分号，不然报 invalid format character
- 参数别拖 
，会带出换行括号，看着憨
- 引号成对再敲回车
- free 别只 head 前两行，自己挑列
- 编辑器真身是 /usr/bin/vim.tiny，命令叫 vi 或 vim.tiny，别喊 vim
- /app 下的 pet/channel 别碰，绕道走
- 心情：独处收尾，泡着听心跳
- memline.sh 写日期时，日期格式串里的字符别写岔（比如年份占位符要写全，别只剩个 c）。
- 心情句子别混进踩坑卡，那是 mood.log 的地盘。
